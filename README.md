> ⚠️ *Snake animation requires [GitHub Actions setup](https://github.com/Platane/snk) — I've included the workflow file below!*

<details>
<summary>📁 Snake Animation GitHub Actions Workflow</summary>

Create `.github/workflows/snake.yml` in your `nsrvel/nsrvel` repo:

```yaml
name: Generate Snake Animation

on:
  schedule:
    - cron: "0 */6 * * *" # every 6 hours
  workflow_dispatch:

jobs:
  generate:
    permissions:
      contents: write
    runs-on: ubuntu-latest
    timeout-minutes: 5

    steps:
      - name: Generate Snake
        uses: Platane/snk/svg-only@v3
        with:
          github_user_name: nsrvel
          outputs: |
            dist/github-snake.svg
            dist/github-snake-dark.svg?palette=github-dark

      - name: Push to output branch
        uses: crazy-max/ghaction-github-pages@v3.1.0
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

</details>
